|---|---|---|---|---|---|---|
| [ARIN Whois-RWS](https://www.arin.net/resources/registry/whois/rws/api/) | ARIN's older Whois REST service (not the RDAP host) returning net, org and customer records as JSON for an IP. | `https://whois.arin.net/rest/ip/8.8.8.8.json` | ARIN Whois terms of use | US | none | 200 |
| [AWS DynamoDB regional /ping](https://github.com/ekalinin/awsping) | Plain-text health response from a regional DynamoDB endpoint. Browser tools use it to measure latency to each AWS region, and you can swap the region in the hostname. | `https://dynamodb.us-east-1.amazonaws.com/ping` | fair use | US | none | 200 |
| [Google DoH CAA Lookup](https://developers.google.com/speed/public-dns/docs/doh/json) | JSON DNS answer of a domain's CAA records, to verify which CAs may issue certificates for the host. | `https://dns.google/resolve?name=google.com&type=CAA` | Google Public DNS terms; fair use | global | none | 200 |
| [Google DoH HTTPS (SVCB) record lookup](https://developers.google.com/speed/public-dns/docs/doh/json) | JSON DNS answer for the HTTPS record type, exposing ALPN (h3/h2), ECH and IP hints that affect HTTP/3 discovery. | `https://dns.google/resolve?name=cloudflare.com&type=HTTPS` | Google Public DNS terms; fair use | global | none | 200 |
| [Google Public DNS DoH (RFC 8484 wire)](https://developers.google.com/speed/public-dns/docs/doh) | Returns a binary application/dns-message answer for a base64url-encoded query (here example.com A). Use it to test native DoH client behaviour and timing. | `https://dns.google/dns-query?dns=AAABAAABAAAAAAAAB2V4YW1wbGUDY29tAAABAAE` | fair use | global | none | 200 |
| [Google Public DNS JSON](https://developers.google.com/speed/public-dns/docs/doh/json) | Resolves any DNS record type as JSON with DNSSEC flags (AD, CD). Useful for checking CDN CNAME chains, TTLs and apex/www setup. | `https://dns.google/resolve?name=www.wikipedia.org&type=CNAME&do=1` | fair use; no published hard limit | global | none | 200 |
| [IP Guide](https://ip.guide/) | Free JSON API giving IP, enclosing network CIDR, ASN, organisation and location for an address. | `https://ip.guide/1.1.1.1` | fair use | global | none | 200 |
| [ip-api.com geolocation](https://ip-api.com/docs/api:json) | JSON with country, city, ISP, org and AS for an IP or domain, with a fields filter. The free endpoint is HTTP-only and limited to 45 req/min. | `http://ip-api.com/json/1.1.1.1?fields=status,country,countryCode,regionName,city,isp,org,as,query` | free for non-commercial use; 45 req/min | global | none | 200 |
| [ipverse as-ip-blocks](https://github.com/ipverse/as-ip-blocks) | Daily-updated JSON of aggregated IPv4/IPv6 prefixes per ASN with handle, country and category, as a static BGPView replacement. | `https://raw.githubusercontent.com/ipverse/as-ip-blocks/master/as/13335/aggregated.json` | see repo license | global | none | 200 |
| [RIPE Database REST (aut-num)](https://docs.db.ripe.net/RIPE-Database-Structure/) | Raw RIPE DB object for an ASN as JSON, including import/export policy, org and contacts. | `https://rest.db.ripe.net/ripe/aut-num/AS3333.json` | RIPE Database terms (fair use) | EU | none | 200 |
| [RIPEstat announced-prefixes](https://stat.ripe.net/docs/02.data-api/announced-prefixes.html) | Lists all prefixes an ASN currently announces in BGP, so you can map an ASN to the IP ranges of a CDN or host. | `https://stat.ripe.net/data/announced-prefixes/data.json?resource=AS13335` | RIPEstat terms (fair use) | global | none | 200 |
| [RIPEstat AS Overview](https://stat.ripe.net/docs/data-api/api-endpoints/as-overview) | JSON with the holder name and announcement status for an ASN. Use it to identify the network or CDN behind an AS. | `https://stat.ripe.net/data/as-overview/data.json?resource=AS13335` | RIPEstat usage rules; register past 1000 req/day | global | none | 200 |
| [RIPEstat Network Info](https://stat.ripe.net/docs/data-api/api-endpoints/network-info) | Maps an IP to its covering BGP prefix and origin ASN as JSON. Use it to find which AS serves an edge IP. | `https://stat.ripe.net/data/network-info/data.json?resource=1.1.1.1` | RIPEstat usage rules | global | none | 200 |
| [RIPEstat prefix-overview](https://stat.ripe.net/docs/02.data-api/prefix-overview.html) | Returns the announcing ASN, holder and block for a prefix or IP, to identify which network serves a CDN edge. | `https://stat.ripe.net/data/prefix-overview/data.json?resource=1.1.1.0/24` | RIPEstat terms (fair use) | global | none | 200 |
| [RIPEstat rpki-validation](https://stat.ripe.net/docs/02.data-api/rpki-validation.html) | RPKI validity (valid/invalid/unknown) for an origin ASN plus prefix pair, for diagnosing routing-security or reachability problems. | `https://stat.ripe.net/data/rpki-validation/data.json?resource=AS13335&prefix=1.1.1.0/24` | RIPEstat terms (fair use) | global | none | 200 |
| [Root Hints (named.root)](https://www.iana.org/domains/root/files) | InterNIC file listing root server names and IPs, for setting up resolvers or testing root reachability. | `https://www.internic.net/domain/named.root` | fair use | global | none | 200 |
